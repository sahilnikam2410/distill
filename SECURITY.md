# Security policy

distill is a prompt (`SKILL.md`) plus a standard-library Python script. It makes no
network calls and handles no credentials.

If you find a security issue, for example a rule that could make Claude drop a
security warning or run a destructive command without confirmation, please report
it privately through
[GitHub security advisories](https://github.com/sahilnikam2410/distill/security/advisories/new)
rather than a public issue. You will get a reply within 7 days.
